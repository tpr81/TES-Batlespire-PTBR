# 🇧🇷 The Elder Scrolls: Battlespire — Tradução PT-BR

Projeto comunitário de **tradução para português brasileiro (PT-BR)** de **The Elder Scrolls: Battlespire**, jogo da série *The Elder Scrolls* lançado pela Bethesda Softworks.

## 📖 Sobre o projeto

O objetivo deste projeto é traduzir *The Elder Scrolls: Battlespire* para **português brasileiro**, permitindo que jogadores brasileiros possam aproveitar o jogo com seus textos traduzidos.

A tradução busca preservar o significado original dos textos, mantendo a ambientação, o contexto e a personalidade dos personagens do jogo.

## 🎮 Jogo

# 🧪 Testes

Os textos traduzidos devem ser testados diretamente no jogo para verificar:

* Textos cortados.
* Caracteres incompatíveis.
* Problemas de acentuação.
* Limitações de tamanho.
* Quebras de linha incorretas.
* Erros de contexto.
* Problemas de carregamento dos arquivos.

## ⚠️ Aviso

Este é um **projeto de tradução não oficial**.

*The Elder Scrolls: Battlespire*, seus arquivos originais, personagens, nomes, marcas e demais elementos pertencem aos seus respectivos detentores de direitos.

Este projeto não possui vínculo oficial com a Bethesda Softworks.

Os arquivos originais do jogo **não são redistribuídos por este projeto**.
